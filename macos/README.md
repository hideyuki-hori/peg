# Peg for macOS

macOS 向けのランチャーアプリです。Dock には表示されず、メニューバーに日時とバッテリー残量を `MM/dd(曜日) HH:mm:ss 100%` の形で表示して常駐します（充電中は `100%(充電中)`）。これから作る機能を含む仕様は [SPEC.md](SPEC.md) にあります。

## 機能

| 操作 | 動作 |
|---|---|
| cmd+space | パレットを表示。`apps.csv` に書いたアプリの起動、計算、最前面アプリのメニュー項目の実行、付箋を開く |
| メニューバーの日時をクリック | 真下にカレンダーと予定を表示。もう一度押すか外側をクリックすると閉じる |
| cmd を素早く2回 | クリップボード履歴を表示し、選んだ項目をクリップボードへ書き込み |
| fn を素早く2回 | 付箋を表示 / 隠す |

クリップボード履歴は選んだ項目をクリップボードへ流すだけで、アプリへの貼り付けは行いません。

### パネル内のキー操作

| キー | 動作 |
|---|---|
| ↑ / ↓、ctrl+p / ctrl+n | 選択を移動 |
| tab | ヒント入力に切り替え。各行の右端の文字（a s d f g h j k l の 1〜2 文字）を打つとその行を実行。もう一度 tab か esc で戻る |
| return | 起動 / コピー |
| esc | 閉じる |
| cmd+Q | Peg を終了 |

文字を入力すると一覧を絞り込めます。

### メニュー検索

パレットに文字を入力すると、最前面のアプリのメニュー項目も候補に出ます。検索はメニューの階層をつないだ名前（例: `ファイル > 書き出す > PDF`）が対象なので、どこにあるかを知らなくても見つかります。選ぶと、その項目をクリックしたのと同じ動作をします。

- アクセシビリティ API で読み取るため、アクセシビリティの許可が必要です
- 無効な項目と、「再起動」のように確認なしの隠し項目は出しません
- 開くまで中身が空のサブメニュー（Electron 製アプリの一部）は読めません
- `PEG_MENU_LIVE=1 swift test --filter MenuReaderLiveTests` で、Finder のメニューを実際に読み取るテストを実行できます

### 付箋をパレットから開く

パレットには付箋も候補に出ます（入力がないときは新しい 8 枚、入力があるときは題名で絞り込み）。選ぶとその付箋を開きます。「新しい付箋」を選ぶと新しく作ります。

### カレンダー

メニューバーの日時をクリックすると、その下にカレンダーが出ます。

- 月の表示と、今日と明日の予定を表示します。日付を押すとその日の予定になり、「今日」を押すと戻ります
- 予定は macOS のカレンダーから読み込みます。Google カレンダーを表示するには、システム設定 > インターネットアカウント で Google アカウントを追加し、カレンダーをオンにしてください
- 予定の URL、場所、メモのいずれかに Google Meet の URL があると、Meet ボタンを表示します。押すとブラウザで開きます
- 国民の祝日は日曜と同じ色で表示します。判定には、名前に「祝日」か「holiday」を含むカレンダー（Google の「日本の祝日」など）の終日の予定を使います。Google 側の祝日カレンダーの設定は「祝日のみ」にしてください（「祝日と行事」だと大晦日なども休みの色になります）。祝日カレンダーがないときは、法律に基づく計算で代用します
- 初回は「許可」ボタンからカレンダーへのアクセスを許可してください

### 計算

ランチャーに式を入力すると、一覧の先頭に計算結果を表示します。return で結果をクリップボードへ書き込みます。結果はクリップボード履歴にも残ります。

| 入力 | 結果 |
|---|---|
| `1+2` | 3 |
| `(1+2)*3` | 9 |
| `7/2` | 3.5 |
| `2^10` | 1024 |
| `1,000+2,000` | 3000 |

- 使える記号は `+` `-` `*` `/` `^` `(` `)` です。`×` `÷` と全角の数字や記号も使えます
- 小数は小数点以下10桁までに丸めます
- 数字だけの入力や、0 での割り算などの計算できない式では、結果を表示しません

### ランチャーの左右のカード

> 現在は使っていません。コードは残してあり、呼び出しだけ外しています（[SPEC.md](SPEC.md) の「仕様に入れないもの」）。

cmd+space でランチャーを開くと、ランチャーの上と左右にカードを表示します。クリップボード履歴（cmd を2回）では表示しません。

| 項目 | 内容 |
|---|---|
| 日時（上） | 現在の日時を `yyyy-MM-dd(曜日) HH:mm:ss` で表示。右端に Peg の終了ボタン |
| カレンダー（左） | 月の表示と、今日と明日の予定。日付を押すとその日の予定を表示 |
| バッテリー（左） | 残量、充電状態、残り時間、最大容量 |
| Wi-Fi（右） | オン / オフ、接続中のネットワーク、近くにある既知のネットワークへの接続 |
| ToDo（下） | タスクの追加、完了、削除。Obsidian の保管庫に保存 |
| Bluetooth（右） | オン / オフ、デバイスの接続 / 切断、バッテリー残量 |

- 予定は macOS のカレンダーから読み込みます。Google カレンダーを表示するには、システム設定 > インターネットアカウント で Google アカウントを追加し、カレンダーをオンにしてください
- 予定のある日には、日付の下に点を表示します
- 日付を押すとその日の予定を表示します。「今日」を押すか、パネルを開き直すと、今日と明日の表示に戻ります
- 予定の URL、場所、メモのいずれかに Google Meet の URL があると、Meet ボタンを表示します
- 接続中の Bluetooth デバイスをクリックすると切断します。キーボードやマウスを切断すると操作できなくなるので注意してください
- 画面の幅が狭い場合は、左右のカードの幅を縮めます。それでも収まらない場合は、左右のカードを表示しません
- パネルの表示中は背景をぼかします。ぼかした領域をクリックするか、esc で閉じます

## 必要環境

- macOS 14 以降
- Swift 5.9 以降（Xcode 15 以降）

## ビルドと起動

リポジトリのルートで次を実行すると、ビルドして起動し直します。

```sh
./run.sh
```

中身は次と同じです。

```sh
./scripts/build-app.sh
pkill -x Peg; open dist/Peg.app
```

初回は、署名用の自己署名証明書「Peg Dev Signing」をログインキーチェーンに作ります（ログインパスワードの確認が出ます）。以後は毎回この証明書で署名するので、再ビルドしてもアクセシビリティの許可は外れません。証明書の名前は環境変数 `PEG_SIGN_IDENTITY` で変えられます。

テストは次のコマンドで実行します。

```sh
swift test
```

## 初回設定

### cmd+space

Spotlight のショートカットと重なるため、システム設定 > キーボード > キーボードショートカット > Spotlight で「Spotlight 検索を表示」をオフにしてください。

### アクセシビリティ権限

cmd と fn の2回押しを検出するために必要です。システム設定 > プライバシーとセキュリティ > アクセシビリティ で Peg を許可してください。

許可は「Bundle ID と署名証明書」の組に対して付くので、同じ証明書で署名し続ければ再ビルドしても残ります。アドホック署名のビルドから切り替えた直後は、古い登録を消してから付け直してください。

```sh
tccutil reset Accessibility app.peg.macos
open dist/Peg.app
```

### カードの権限

> 現在は使っていません。コードは残してあり、呼び出しだけ外しています（[SPEC.md](SPEC.md) の「仕様に入れないもの」）。

| 権限 | 用途 | 許可しない場合 |
|---|---|---|
| カレンダー | 予定の表示 | 予定を表示しません |
| 位置情報 | Wi-Fi のネットワーク名の取得 | ネットワーク名と既知のネットワークを表示しません |
| Bluetooth | デバイスの接続と切断 | 接続と切断ができません |

カレンダーと位置情報は、カード内の「許可」ボタンを押すと確認が表示されます。位置情報は macOS の仕様でネットワーク名の取得に必要なもので、現在地は取得しません。

## 設定

設定は `~/.config/peg/` に置きます。

| ファイル | 内容 |
|---|---|
| `apps.csv` | 起動できるアプリのパス |
| `config.json` | 保管庫のパスなどの設定 |
| `clipboard.json` | クリップボード履歴（自動生成） |
| `sync-state.json` | 前回の同期の記録（自動生成） |

### apps.csv

1行に1つ、アプリのパスを書きます。変更はパネルを開くたびに反映されます。

```
/Applications/Blender.app
/Applications/Google\ Chrome.app
"/Applications/Logic Pro.app"
~/Applications/Foo.app
```

- スペースは `\ ` でエスケープするか、パス全体を `"` で囲みます
- 重複した行は1つにまとめます
- 存在しないパスは一覧に表示しません

### config.json

```json
{
  "vaultPath": "~/vaults"
}
```

| 項目 | 内容 |
|---|---|
| `vaultPath` | Obsidian の保管庫のパス。ToDo の保存先になります |

### ToDo

> 現在は使っていません。コードは残してあり、呼び出しだけ外しています（[SPEC.md](SPEC.md) の「仕様に入れないもの」）。

保管庫の `peg/todo.md` に、Obsidian のチェックリストの書き方で保存します。Obsidian で編集した内容は、パネルを開いたときと、開いている間の5秒ごとに読み込みます。

```markdown
- [ ] 請求書を送る 📅 2026-09-26
- [ ] 歯医者を予約する
- [x] 牛乳を買う
```

- 未完了のタスクを上に、完了済みのタスクを下に表示します。それぞれの中はファイルに書かれた順です
- 追加欄で題名の末尾に `@9/30` または `@2026-09-30` と書くと、期限になります。月日だけを書いて過ぎた日付だった場合は、翌年として扱います
- 期限を過ぎた未完了のタスクは、期限を赤系の色で表示します
- タスク以外の行（見出しやメモ）は変更しません
- タスクを変更すると、保管庫を R2 に同期します（`r2` を設定している場合）

### R2 への同期

> 現在は使っていません。コードは残してあり、呼び出しだけ外しています（[SPEC.md](SPEC.md) の「仕様に入れないもの」）。

`config.json` に `r2` を書くと、保管庫を Cloudflare R2 のバケットと同期します。

```json
{
  "vaultPath": "~/peg",
  "r2": {
    "accountId": "",
    "bucket": "",
    "prefix": "",
    "accessKeyId": "",
    "secretAccessKey": ""
  },
  "sync": {
    "deviceName": "mac"
  }
}
```

- `config.json` はシークレットを含むので、パーミッションを 600 にします
- 同期するのは、エディタを開いたとき、エディタで保存したとき、ToDo を変更したとき、`Peg --sync` を実行したときです
- 両方の端末で同じファイルを変更した場合は、R2 にある内容を残し、手元の内容を `<名前>.conflict-<端末名>-<日時>` という別ファイルにします
- ほかの端末で削除されたファイルは、ゴミ箱に移します
- 前回の同期の記録は `sync-state.json` に保存します

### 付箋

fn を素早く2回押すと、開いている付箋をまとめて表示します。付箋は1枚1ウィンドウで、複数枚を並べられます。フォーカスがある状態でもう一度押すと全部隠します。

| キー | 動作 |
|---|---|
| cmd+N | 新しい付箋を別ウィンドウで開きます |
| cmd+[ / cmd+] | 前 / 次の付箋にフォーカスを移します |
| cmd+W | その付箋だけ閉じます（ファイルは残ります） |
| cmd+shift+delete | その付箋をゴミ箱に移します |
| esc | 付箋を全部隠します |

- 付箋は `~/memo` に1枚1ファイルの Markdown で保存します。ファイル名は UUIDv7 で、名前順が作成順になります
- 入力すると自動で保存します。中身が空の付箋は、隠すときや閉じるときに消します
- 開いている付箋と位置・大きさは `~/Library/Application Support/peg/notes/stickies.json` に保存し、次の起動時に同じ場所へ戻します
- 開いている付箋が1枚もないときは、いちばん新しい付箋を開きます
- Markdown をその場で装飾して表示します。対象は見出し、箇条書き、番号付きリスト、チェックボックス、太字、斜体、インラインコード、コードブロック、引用です。ファイルの中身は素の Markdown のままです
- fn の2回押しを使うには、システム設定 > キーボード で「🌐キーを押して」を「何もしない」にし、音声入力のショートカットを fn 2回押し以外に変えてください

### メモのエディタ

> 現在は使っていません。コードは残してあり、呼び出しだけ外しています。付箋に置き換えました。

cmd+shift+space で、保管庫のフォルダをサイドバーに表示するエディタを開きます。もう一度押すと閉じます。

| キー | 動作 |
|---|---|
| cmd+S | 開いているファイルを保存します |
| cmd+N | 新しいメモを作ります。名前に拡張子がなければ `.md` を付け、`フォルダ/名前` と書くとフォルダも作ります |
| cmd+W | ウィンドウを閉じます |

- 自動保存はしません。未保存のファイルは、サイドバーと下部に印を表示します
- 未保存の内容は、ファイルを切り替えてもウィンドウを閉じても、Peg を終了するまで保持します
- `.` で始まるファイルとフォルダは表示しません
- 編集中のファイルがほかの端末の変更で書き換わっていた場合、保存時に編集内容を `<名前>.conflict-<端末名>-<日時>` という別ファイルにします
- 表示するフォルダを保管庫と別にする場合は、`config.json` に `"editor": { "root": "~/notes" }` を書きます

### クリップボード履歴

- テキストのみを対象に、最大100件を保存します
- 同じ内容をコピーした場合は先頭へ移動します
- パスワードマネージャーなどが秘匿対象として指定した内容は保存しません
- `clipboard.json` の権限は 600 です

## 構成

```
macos
├── Package.swift
├── Resources
│   └── Info.plist
├── Sources
│   ├── Peg
│   ├── PegCore
│   ├── PegAXShim
│   ├── PegMenu
│   ├── PegNotes
│   └── PegSync
├── Tests
│   ├── PegCoreTests
│   ├── PegMenuTests
│   ├── PegNotesTests
│   └── PegSyncTests
└── scripts
    └── build-app.sh
```

| ターゲット | 内容 |
|---|---|
| `PegCore` | 計算、ヒント文字の生成、ToDo の読み書き、画面内の配置の計算、`apps.csv` のパース、絞り込み、履歴管理、2回押し検出、月の計算、予定の整理、Meet の URL 抽出、バッテリー / Bluetooth / Wi-Fi 情報の解析 |
| `PegAXShim` | アクセシビリティ API を包む C コード。Swift 側にキャストを持ち込まないため |
| `PegMenu` | メニュー項目の列挙と実行 |
| `PegNotes` | 付箋の保存と一覧、UUIDv7 の生成、Markdown の装飾範囲の解析 |
| `Peg` | アプリ本体（パネル、ホットキー、クリップボード監視、システム情報の取得） |
