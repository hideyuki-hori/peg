# Peg for macOS

macOS 向けのランチャーアプリです。Dock には表示されず、メニューバーに日時とバッテリー残量を表示して常駐します。

## 機能

| 操作 | 動作 |
|---|---|
| cmd+space | ランチャーを表示し、`apps.csv` に書いたアプリを起動。左右に日時や Wi-Fi などのカードを表示 |
| メニューバーの日時をクリック | cmd+space と同じ |
| cmd を素早く2回 | クリップボード履歴を表示し、選んだ項目をクリップボードへ書き込み |

クリップボード履歴は選んだ項目をクリップボードへ流すだけで、アプリへの貼り付けは行いません。

### パネル内のキー操作

| キー | 動作 |
|---|---|
| ↑ / ↓、ctrl+p / ctrl+n | 選択を移動 |
| cmd+n | ToDo の追加欄へ移動 |
| return | 起動 / コピー |
| esc | 閉じる（ToDo の追加欄にいるときは検索欄へ戻る） |

文字を入力すると一覧を絞り込めます。

### 計算

ランチャーに式を入力すると、一覧の先頭に計算結果を表示します。return で結果をクリップボードへ書き込みます。結果はクリップボード履歴にも残ります。

| 入力 | 結果 |
|---|---|
| `1+2` | 3 |
| `(1+2)*3` | 9 |
| `7/2` | 3.5 |
| `2^10` | 1024 |
| `1,000+2,000` | 3000 |

- 使える記号は `+` `-` `*` `/` `^` `(` `)` です。`×` `÷` と全角の数字や記号も使えます
- 小数は小数点以下10桁までに丸めます
- 数字だけの入力や、0 での割り算などの計算できない式では、結果を表示しません

### ランチャーの左右のカード

cmd+space でランチャーを開くと、ランチャーの上と左右にカードを表示します。クリップボード履歴（cmd を2回）では表示しません。

| 項目 | 内容 |
|---|---|
| 日時（上） | 現在の日時を `yyyy-MM-dd(曜日) HH:mm:ss` で表示。右端に Peg の終了ボタン |
| カレンダー（左） | 月の表示と、今日と明日の予定。日付を押すとその日の予定を表示 |
| バッテリー（左） | 残量、充電状態、残り時間、最大容量 |
| Wi-Fi（右） | オン / オフ、接続中のネットワーク、近くにある既知のネットワークへの接続 |
| ToDo（下） | タスクの追加、完了、削除。Obsidian の保管庫に保存 |
| Bluetooth（右） | オン / オフ、デバイスの接続 / 切断、バッテリー残量 |

- 予定は macOS のカレンダーから読み込みます。Google カレンダーを表示するには、システム設定 > インターネットアカウント で Google アカウントを追加し、カレンダーをオンにしてください
- 予定のある日には、日付の下に点を表示します
- 日付を押すとその日の予定を表示します。「今日」を押すか、パネルを開き直すと、今日と明日の表示に戻ります
- 予定の URL、場所、メモのいずれかに Google Meet の URL があると、Meet ボタンを表示します
- 接続中の Bluetooth デバイスをクリックすると切断します。キーボードやマウスを切断すると操作できなくなるので注意してください
- 画面の幅が狭い場合は、左右のカードの幅を縮めます。それでも収まらない場合は、左右のカードを表示しません
- パネルの表示中は背景をぼかします。ぼかした領域をクリックするか、esc で閉じます

## 必要環境

- macOS 14 以降
- Swift 5.9 以降（Xcode 15 以降）

## ビルドと起動

```sh
./scripts/build-app.sh
open dist/Peg.app
```

テストは次のコマンドで実行します。

```sh
swift test
```

## 初回設定

### cmd+space

Spotlight のショートカットと重なるため、システム設定 > キーボード > キーボードショートカット > Spotlight で「Spotlight 検索を表示」をオフにしてください。

### アクセシビリティ権限

cmd の2回押しを検出するために必要です。システム設定 > プライバシーとセキュリティ > アクセシビリティ で Peg を許可してください。

アドホック署名のため、再ビルドすると許可が無効になることがあります。その場合は Peg を一度オフにしてからオンに戻してください。

### カードの権限

| 権限 | 用途 | 許可しない場合 |
|---|---|---|
| カレンダー | 予定の表示 | 予定を表示しません |
| 位置情報 | Wi-Fi のネットワーク名の取得 | ネットワーク名と既知のネットワークを表示しません |
| Bluetooth | デバイスの接続と切断 | 接続と切断ができません |

カレンダーと位置情報は、カード内の「許可」ボタンを押すと確認が表示されます。位置情報は macOS の仕様でネットワーク名の取得に必要なもので、現在地は取得しません。

## 設定

設定は `~/.config/peg/` に置きます。

| ファイル | 内容 |
|---|---|
| `apps.csv` | 起動できるアプリのパス |
| `config.json` | 保管庫のパスなどの設定 |
| `clipboard.json` | クリップボード履歴（自動生成） |

### apps.csv

1行に1つ、アプリのパスを書きます。変更はパネルを開くたびに反映されます。

```
/Applications/Blender.app
/Applications/Google\ Chrome.app
"/Applications/Logic Pro.app"
~/Applications/Foo.app
```

- スペースは `\ ` でエスケープするか、パス全体を `"` で囲みます
- 重複した行は1つにまとめます
- 存在しないパスは一覧に表示しません

### config.json

```json
{
  "vaultPath": "~/vaults"
}
```

| 項目 | 内容 |
|---|---|
| `vaultPath` | Obsidian の保管庫のパス。ToDo の保存先になります |

### ToDo

保管庫の `peg/todo.md` に、Obsidian のチェックリストの書き方で保存します。Obsidian で編集した内容は、パネルを開いたときと、開いている間の5秒ごとに読み込みます。

```markdown
- [ ] 請求書を送る 📅 2026-09-26
- [ ] 歯医者を予約する
- [x] 牛乳を買う
```

- 未完了のタスクを上に、完了済みのタスクを下に表示します。それぞれの中はファイルに書かれた順です
- 追加欄で題名の末尾に `@9/30` または `@2026-09-30` と書くと、期限になります。月日だけを書いて過ぎた日付だった場合は、翌年として扱います
- 期限を過ぎた未完了のタスクは、期限を赤系の色で表示します
- タスク以外の行（見出しやメモ）は変更しません
- ほかの端末への同期は Peg では行いません。Self-hosted LiveSync などを使う場合、Obsidian が起動している間に同期されます

### クリップボード履歴

- テキストのみを対象に、最大100件を保存します
- 同じ内容をコピーした場合は先頭へ移動します
- パスワードマネージャーなどが秘匿対象として指定した内容は保存しません
- `clipboard.json` の権限は 600 です

## 構成

```
macos
├── Package.swift
├── Resources
│   └── Info.plist
├── Sources
│   ├── Peg
│   └── PegCore
├── Tests
│   └── PegCoreTests
└── scripts
    └── build-app.sh
```

| ターゲット | 内容 |
|---|---|
| `PegCore` | 計算、ToDo の読み書き、画面内の配置の計算、`apps.csv` のパース、絞り込み、履歴管理、2回押し検出、月の計算、予定の整理、Meet の URL 抽出、バッテリー / Bluetooth / Wi-Fi 情報の解析 |
| `Peg` | アプリ本体（パネル、ホットキー、クリップボード監視、システム情報の取得） |
