# peg 仕様

## 目的

メニュー操作・アプリ起動・クリップボード・スニペット・Claude 連携・付箋を、マウスを使わずキーボードだけで行うためのアプリ。

メニューバーは隠さない（ノッチのある画面では、隠してもその高さがアプリの表示領域にならないため）。

## 方針

- 言語・UI: Swift / AppKit。対象は macOS 15 以降
- 構成: 単一アプリ。将来の分割に備えた構造にする（「構造」の節）
- 依存: 実行時にサードパーティのランタイムに依存しない。OS 標準 API を中心に使う。外部ライブラリはソースや成果物をアプリに同梱する形に限る
- データ: すべてローカルに、プレーンな形式（JSON / Markdown / SQLite など）で機能ごとに保存する。同期はしない
- 利用者: 自分用。App Sandbox は使わない（アクセシビリティ API を使うため）
- 署名: 自己署名の証明書（`Peg Dev Signing`、ビルドスクリプトが初回に作る）で毎回同じ署名をし、Bundle ID も固定する（ビルドのたびにアクセシビリティ権限が外れるのを防ぐため）
- 操作: すべての機能をキーボードだけで完結させる

## 前提（アプリの外で行う設定）

- Spotlight のショートカット（`⌘Space`）を、システム設定のキーボードショートカットで無効にする
- システム設定のキーボードで「🌐キーを押して」を「何もしない」にし、音声入力のショートカットを fn 2 回押し以外に変える

## 機能

### 1. パレット（共通の入口）

- `⌘Space` で呼び出す（Carbon `RegisterEventHotKey`）
- 表示には非アクティブ化パネル（`NSPanel` + `.nonactivatingPanel`）を使い、最前面アプリをアクティブなまま操作できるようにする
- インクリメンタルなファジー検索で候補を絞り込む
- 絞り込んだ候補に Vimium 風のヒント文字を振る
  - 文字集合はホームロー（`asdfghjkl`）
  - 候補数に応じて、最短で一意になる 1〜2 文字のラベルを生成する。1 文字のラベルをできるだけ多く残す
  - Tab でヒント入力に切り替え、ヒント文字を入力して一意に決まった時点で実行する。Esc か Tab で検索入力に戻る
- 各機能の候補を、このパレットに集約して表示する
  - 並び: 計算結果、アプリ、メニュー項目（入力があるときだけ、40 件まで）、付箋（入力がないときは新しい 8 件、あるときは 20 件まで）、「新しい付箋」
  - クリップボード履歴は ⌘ 2 回押しの別モードのまま（候補が多く、混ぜると検索の邪魔になるため）

### 2. メニュー検索・実行

- Accessibility API（`AXUIElement`）で、最前面アプリの `kAXMenuBarAttribute` からメニュー階層を列挙する
- 検索対象はメニューパス全体（例: `ファイル > 書き出す > PDF`）とし、階層を知らなくても検索で当たるようにする
- 実行は `kAXPressAction`
- 開くまで中身が空になる動的サブメニュー（Electron 製アプリなど）は、親項目を展開してから取得する（未実装。展開するとメニューが画面に開くため、やり方を検討中）
- AX 呼び出しはメインスレッドで行わず、タイムアウト（0.5 秒）を設ける（対象アプリが固まったときの巻き込みを防ぐ）
- AX の C API は `PegAXShim`（C ターゲット）で包み、Swift 側にキャストを持ち込まない
- パレットを開いたときに最前面アプリの分だけ取得する。キャッシュはしない（Finder で 0.3 秒程度）
- 無効な項目と区切り線は候補に出さない。「再起動…」と「再起動」のように確認なしの隠し項目が並ぶときは、確認ありのほうだけを出す
- メニューバー右側のステータス項目（`kAXExtrasMenuBarAttribute`）は検索対象に含めない

### 3. ランチャー

- 起動対象は、設定ファイルに記載した Bundle ID のホワイトリストに限る
- 起動は `NSWorkspace.openApplication`
- 入力が数式なら計算結果を候補として出し、Enter で結果をコピーする

### 4. クリップボード履歴

- `NSPasteboard.changeCount` を 0.5 秒間隔でポーリングして変更を検出する
- `org.nspasteboard.ConcealedType` / `org.nspasteboard.TransientType` が付いた内容は保存しない（パスワードマネージャー対策）
- 扱うのはテキストのみ。最新 500 件を SQLite に保持する
- 貼り付けは、選択した内容をペーストボードに戻してから `⌘V` のキーイベントを送信する
- 最新の macOS で、他アプリのクリップボード読み取り時にプライバシー確認が出るかを実装時に確認する

### 5. スニペット

- 保存したテキストをパレットから検索して選び、貼り付ける
- 略語による自動展開は行わない

### 6. Claude / Claude Code へのアクセス

- Claude Code: ホワイトリストに登録したプロジェクトディレクトリを検索で選び、ターミナルでそのディレクトリを開いて `claude` を起動する。ターミナルアプリは設定ファイルで指定する
- Claude: デスクトップアプリを起動・前面化する
- 外部サービスとの連携部分は 1 箇所にまとめ、差し替えやすくする

### 7. 付箋

- 画面上に浮かぶフローティングパネル（`NSPanel`）として表示する。1 付箋 1 ウィンドウで、複数枚を同時に並べられる
- 入口は fn をすばやく 2 回。開いている付箋をまとめて表示し、直前の付箋にフォーカスする。フォーカスがある状態なら全部隠す。出ているがフォーカスがないときはフォーカスを移す
  - 開いている付箋が 1 枚もなければ、いちばん新しい付箋を開く。付箋が 1 枚もなければ新しく作る
  - 検出は `flagsChanged` の監視で行う（fn 単体は Carbon のホットキーに登録できないため）
  - 押してから離すまで 0.3 秒以内、2 回の間隔 0.4 秒以内を 2 回押しとみなす
- キー操作
  - 新しい付箋を別ウィンドウで開く: `⌘N`
  - 開いている付箋の間でフォーカスを移す: `⌘[` / `⌘]`
  - その付箋だけ閉じる（ファイルは残る）: `⌘W`
  - 全部隠す: `Esc` または fn 2 回
  - 削除: `⌘⇧⌫`（ゴミ箱に移す。`⌘⌫` は行頭までの削除という編集操作なので使わない）
- 開いている付箋と、それぞれの位置・大きさを `~/Library/Application Support/peg/notes/stickies.json` に保存し、次の起動時に同じ場所へ戻す
- 中身が空の付箋は、隠すときや閉じるときにファイルごと消す
- パレットの検索候補にも付箋を出す。選ぶとその付箋を開く
- 中身は Markdown。1 付箋 1 ファイルで `~/memo` に保存する。自動保存
  - ファイル名は UUIDv7 + `.md`（先頭が作成時刻なので、名前順が作成順になる）
  - UUIDv7 は自前で生成する
  - 付箋のタイトルは本文の 1 行目から取る（一覧や検索での表示用。ファイル名には使わない）
- エディタは `NSTextView`。入力した Markdown をその場でスタイリングする
  - `# aaa` と書くと、その行が見出しの大きさ・太さで表示される
  - 対象は見出し、箇条書き、番号付きリスト、チェックボックス、太字、斜体、インラインコード、コードブロック、引用
  - ファイルの中身は素の Markdown のまま。変えるのは表示だけ
- 表やデータベースなどのブロックは扱わない

### 8. メニューバーの日時・バッテリー表示

- メニューバーに日時とバッテリー残量を `MM/dd(曜日) HH:mm:ss 100%` の形で表示する。充電中は `100%(充電中)`
- クリックすると、その真下にカレンダーをポップオーバーで出す
  - 月の表示と、今日と明日の予定。日付を押すとその日の予定
  - 予定は macOS のカレンダー（EventKit）から読む。Google カレンダーはシステム設定のインターネットアカウントで追加しておく
  - 予定に Google Meet の URL があれば Meet ボタンを出し、押すとブラウザで開く
  - 国民の祝日は日曜と同じ色にする。名前に「祝日」か「holiday」を含むカレンダー（Google の「日本の祝日」など）の終日の予定を祝日とみなす。そのカレンダーがなければ `JapaneseHolidays` の計算で代用する
  - 外側をクリックすると閉じる

## 構造（将来の分割に備える）

- Swift Package は 1 つ。機能ごとにターゲットを分け、機能ターゲット同士は依存させず、アプリ本体を経由させる
- 新しく作る機能は最初から専用ターゲットにする。既存の機能は手を入れるときに移す
- モジュール間の呼び出しは最初から非同期（async）にする
- モジュール間で共有状態（シングルトン、グローバル変数）を持たない
- モジュール間で受け渡すデータは Codable な値型（構造体）に限る
- データ保存先は機能ごとに分ける
  - 設定: `~/.config/peg/config.json`
  - 付箋: `~/memo`
  - クリップボード履歴・スニペット: `~/Library/Application Support/peg/` 配下に機能ごと
- アプリ分割とアプリ間メッセージング（ブローカー）は作らない

## 仕様に入れないもの

- R2 への同期、ToDo、Wi-Fi・Bluetooth・バッテリーのカード
- ⌘ 2 回押し（クリップボード履歴）の入口（パレットに集約するまでは残す）と、`⌘⇧Space` のエディタ
- これらの既存コードは削除せず、呼び出しだけ外す

## 必要な権限

- アクセシビリティ: メニュー検索・実行、貼り付けのキーイベント送信、fn 2 回押しの検出
